# Mi Változott? 🎉

## Új Admin Panel!

Az alkalmazás most már egy **modern, gyönyörű admin felülettel** rendelkezik!

### Gyors Indítás:

```bash
# 1. Indítsd el az alkalmazást
python main.py

# 2. Nyisd meg a böngészőben
http://localhost:8000
```

### Mit Kapsz?

✅ **Dashboard** - Statisztikák és élő adatok  
✅ **API Beállítások** - Kulcsok kódolás nélkül!  
✅ **Prompt Szerkesztő** - AI válaszok testreszabása  
✅ **Teszt Interface** - Azonnali próba  
✅ **Lead & Website Kezelés** - Minden egy helyen  

### Példa Prompt Szerkesztésre:

1. Menj az "AI Promptok" oldalra
2. Kattints "Új Prompt"
3. Írd be:
```
Készíts egy modern, reszponzív weboldalt {business_name} számára.
Cím: {address}
Stílus: Elegáns, professzionális, magyar nyelvű.
```
4. Mentsd el
5. Azonnal használható!

### API Kulcsok Beállítása:

1. "API Beállítások"
2. Írd be az OpenAI kulcsot
3. Írd be a Google Maps kulcsot
4. Mentés
5. **Kész!** Nincs több `.env` szerkesztés!
